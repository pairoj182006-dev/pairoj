1. เหตุผลที่อยากเรียน Full Stack Web Development

  เหตุผลที่ผมสนใจเรียนการพัฒนาเว็บไซต์แบบ Full Stack เพราะอยากมีความรู้และเข้าใจการทำงานของเว็บไซต์ทั้งในส่วน Front-end และ Back-end
เพื่อให้สามารถพัฒนา Web Application ได้ด้วยตัวเองตั้งแต่เริ่มต้นจนสามารถนำไปใช้งานจริงได้ นอกจากนี้ยังอยากพัฒนาทักษะและเรียนรู้เทคโนโลยีใหม่ๆ
ให้ทันกับการเปลี่ยนแปลงของสายงานด้านไอทีในปัจจุบัน เพื่อเตรียมตัวสำหรับการทำงานในอนาคต

2. ความคาดหวังต่อวิชานี้

  สิ่งที่คาดหวังจากการเรียนครั้งนี้คือ อยากได้เรียนรู้หลักการออกแบบและพัฒนาเว็บไซต์ที่ถูกต้อง รวมถึงได้ลงมือทำ Workshop หรือ Project จริง
ที่สามารถนำความรู้ไปใช้แก้ปัญหาได้ เพื่อนำไปพัฒนาทักษะและประยุกต์ใช้ในการทำงานจริงในอนาคต รวมถึงอยากเข้าใจการทำงานของฐานข้อมูล
และการเชื่อมต่อ API ให้มากขึ้น เพื่อให้สามารถนำไปพัฒนาเว็บไซต์ได้อย่างถูกต้องและมีประสิทธิภาพ

3. จุดอ่อนที่ต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา

  จุดอ่อน: ตอนนี้ผมยังไม่ค่อยเข้าใจการจัดการ Logic ที่มีความซับซ้อนมากนัก และเวลาพบข้อผิดพลาดในโค้ดมักจะใช้เวลาค่อนข้างนานในการหาสาเหตุและแก้ไข
  แนวทางการพัฒนา: ผมจะฝึกเขียนโค้ดบ่อย ๆ เพื่อให้เข้าใจมากขึ้น รวมถึงศึกษาเพิ่มเติม และฝึกใช้เครื่องมือ Debug เพื่อให้แก้ปัญหาโค้ดได้เร็วและเป็นระบบมากขึ้น
